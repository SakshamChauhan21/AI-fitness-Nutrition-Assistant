# 🏋️ FitCoach AI

FitCoach AI is an intelligent, evidence-based fitness and nutrition assistant powered by **Groq (Llama/Qwen models)** with native tool calling, built with **Streamlit** and **SQLite**.

## ✨ Features
* **Conversational Profile Setup:** Tracks your age, sex, weight, height, activity level, and goals.
* **Automated Macro & Calorie Calculation:** Computes BMR, TDEE, and daily targets dynamically using standard nutritional formulas.
* **Meal & Workout Logging:** Easily log meals and workouts through natural conversation.
* **Daily Summary Dashboard:** View your daily nutrition totals, remaining macros, and logged workouts in real-time.

## 🛠️ Tech Stack
* **Frontend/UI:** Streamlit
* **AI / LLM:** Groq API (Function/Tool Calling)
* **Database:** SQLite
* **Environment Management:** Python-dotenv
